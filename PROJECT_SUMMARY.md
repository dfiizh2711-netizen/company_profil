## 📞 Support & Resources

### If You Get Stuck:
1. Check `TUTORIAL.md` for code examples
2. Check browser console (F12) for errors
3. Check Supabase logs
4. Google the error message
5. Review example files in `EXAMPLES/`

### Common Issues:
- **Data not loading** → Check config.js
- **Login failed** → Check admin role in database
- **Upload failed** → Check storage bucket permissions
- **CORS error** → Use local server, not file://
